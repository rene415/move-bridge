# Changelog

The app shows the newest entry once after each update ("What's new").

## 0.18: first public release
- **Sending needs no setup:** plug in the Move, tap Start, approve Android's capture prompt.
- **Starts when the Move connects**, with a Stop button in the notification and a Quick Settings tile.
- **Mute notifications while sending**, so rings and pings don't land in samples.
- **The steps on the Move** follow Ableton's manual, with a tip about monitoring and a link to the manual.
- **Send feedback** screen, and an offer to send a crash report after a crash. Nothing is sent unless you send it.
- **Advanced mode** (optional, off by default): Android plays straight to the Move, like USB-C headphones. Less delay, no capture prompt, and the phone can stay silent. Needs a one-time setup in Android's Developer options. See [docs/advanced.md](docs/advanced.md).
- Apache-2.0 license; the licenses of included code are listed in the app.

Versions 0.3 to 0.17 were private test builds.
